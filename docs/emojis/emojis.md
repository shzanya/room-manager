# Паки иконок (эмодзи)

Бот сам превращает иконки в эмодзи Discord и перекрашивает их. Чтобы добавить
свою тему — достаточно положить папку, код менять не нужно.

## Куда класть

```
apps/bot/assets/emojis/packs/<имя-пака>/
```

Каждая папка внутри `packs/` — отдельный пак. Он автоматически появится в
`/setup settings` → **Иконки** → **Пак иконок** после перезапуска бота.

Пример структуры:

```
apps/bot/assets/emojis/packs/
├── niako/          ← пак по умолчанию
│   ├── limit.png
│   ├── lock.png
│   ├── rename.png
│   ├── owner.png
│   ├── kick.png
│   ├── mute.png
│   ├── access.png
│   ├── sounpad.png
│   └── activati.png
└── my-pack/        ← ваша папка
    └── ...
```

## Имена файлов

| Файл            | За что отвечает                        |
| --------------- | -------------------------------------- |
| `limit.png`     | лимит участников                       |
| `lock.png`      | закрыть комнату (+ «открыть»)          |
| `rename.png`    | переименование                         |
| `owner.png`     | передача владельца                     |
| `kick.png`      | кик из комнаты                         |
| `mute.png`      | мут (+ «вернуть звук»)                 |
| `access.png`    | выдать / забрать доступ                |
| `sounpad.png`   | саундпад в меню комнаты                |
| `activati.png`  | активности в меню комнаты              |

Нужны хотя бы базовые файлы — чего не хватает, бот возьмёт из другого пака.

## Как это работает

1. При старте бот сканирует все папки в `packs/`.
2. Когда панель впервые нужна иконка — она загружается на Discord как эмодзи
   приложения (`RM_<действие>_<цвет>`), перекрашенная под выбранный цвет.
3. Загрузки кэшируются по содержимому (`data/emoji-cache.json`): одинаковые
   пиксели никогда не грузятся повторно.
4. Выбор пака — `/setup settings` → **Иконки** → **Пак иконок**.
5. Цвет всех иконок сразу — пресет **Rainbow**, список «Цвет всех иконок» или
   пресет по умолчанию.

## Требования к файлам

- Формат: `.png` или `.webp`
- Желательно: квадрат, прозрачный фон, белая/светлая фигура — именно она
  перекрашивается в выбранный цвет
- Размер: до 512×512 (бот сам нормализует в PNG)
