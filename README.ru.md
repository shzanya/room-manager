## 🌟 Обзор

**Room Manager** автоматизирует создание и управление временными голосовыми каналами на вашем Discord-сервере.

### Принцип работы

1. Пользователь заходит в канал-хаб, например `➕ Создать комнату`.
2. Бот мгновенно создает личный голосовой канал в нужной категории, настраивает права и выдает создателю статус владельца.
3. Владелец получает удобный интерфейс управления — в текстовом чате или прямо внутри голосового канала.
4. Когда все участники покидают комнату, бот автоматически удаляет её по настраиваемому таймеру.

---

## ✨ Ключевые возможности

- ⚡ **Мгновенное создание комнат:** Нулевые задержки, атомарное создание каналов и синхронизация прав.
- 🎨 **2 готовых визуальных скина:** Классический информативный **Niako** и ультра-минималистичный **Aruku**.
- 🎛️ **Гибкие поверхности управления:** Управление через постоянную кнопочную панель в чате, через выпадающее меню внутри голосового канала или в комбинированном режиме.
- 🎭 **Динамическая перекраска иконок:** Бот сам перекрашивает иконки кнопок в выбранный HEX-цвет и загружает их как эмодзи приложения.
- 🛡️ **Защита от спама и рейдов:** Кулдауны на создание комнат, блокировка пересоздания и защита от зацикливания.
- 🌐 **Двуязычность (i18n):** Полная поддержка русского (`ru`) и английского (`en`).
- 🚀 **Оптимизирован по умолчанию:** Работает в быстром легковесном однопоточном режиме без лишней нагрузки на память. Шардинг доступен по флагу для крупных серверов.

## 🎨 Два скина панели управления

В Room Manager встроено два продуманных дизайна интерфейса для интерактивной панели:

```text
┌───────────────────────────────────┬───────────────────────────────────┐
│        Скин 1: Niako (Default)    │        Скин 2: Aruku (Minimal)   │
├───────────────────────────────────┼───────────────────────────────────┤
│ • Классический богатый Embed      │ • Ультра-чистый минимализм        │
│ • Акцентная полоса цвета сервера  │ • Никакого текстового шума        │
│ • Заголовок + подробная подсказка │ • Графический арт-баннер          │
│ • Список всех 10 действий панели  │ • Только кнопки управления         │
│ • Баннер + 2 ряда кнопок          │ • Идеально для эстетичных серверов │
└───────────────────────────────────┴───────────────────────────────────┘
```

### 1. Скин «Niako» (Классический / По умолчанию)

- **Концепция:** Полная информативность и наглядность.
- **Структура:**
  - **Цветной Embed-контейнер:** Настраиваемый акцентный цвет, по умолчанию `#2B2D31`.
  - **Информационный блок:** Заголовок `—・Управление приватной комнатой` и подсказка со стрелкой.
  - **Интерактивный список:** Описание всех действий и соответствующих иконок прямо в теле сообщения.
  - **Баннер:** Анимированный GIF или статический PNG.
  - **Кнопки управления:** 2 компактных ряда кнопок с кастомными цветными эмодзи.

### 2. Скин «Aruku» (Минималистичный / Эстетичный)

- **Концепция:** Чистый дизайн без визуального мусора.
- **Структура:**
  - **Режим `minimal: true`:** Отсутствует Embed, заголовок и текстовое описание.
  - **Графический арт-баннер:** Фирменный баннер высокой четкости `assets/panel/banners/aruku.png`.
  - **Панель кнопок:** Аккуратная панель из 10 кнопок управления расположена прямо под баннером.
  - Отличный выбор для игровых сообществ и аниме-серверов.

> [!TIP]
> Переключить скин можно в любой момент через:
>
> `/setup settings` → **Дизайн** → **Шаблоны** → выбрать `Niako` или `Aruku`.

## 💬 Управление в чате и голосе

Room Manager поддерживает **три режима взаимодействия** (`/setup settings` → **Управление**):

1. **`chat` (Только чат):** Управление осуществляется через закрепленную кнопочную панель в специальном текстовом канале, например `#💬-управление-комнатами`. Внутри войса меню не отправляется.

2. **`voice` (Только голос):** При создании комнаты в её встроенный текстовый чат отправляется меню Components V2. Отдельный текстовый канал панели не требуется.

3. **`both` (Оба режима / По умолчанию):** Максимальное удобство — панель доступна в текстовом канале, а быстрые настройки — прямо внутри чата голосовой комнаты.

### 🎛️ Интерактивные кнопки управления

Вся работа с кнопками происходит через приватные модальные окна и селекторы — **никакого спама в общий чат**!

| Кнопка | Действие | Описание |
| :---: | :--- | :--- |
| 👥 | **Лимит** (`room:limit`) | Установка лимита участников от `0` — без ограничений, до `99`. |
| 🔒 | **Закрыть** (`room:lock`) | Закрывает вход для роли `@everyone`. |
| 🔓 | **Открыть** (`room:unlock`) | Открывает свободный доступ в комнату. |
| ➕ | **Выдать доступ** (`room:access:add`) | Персонально открывает доступ выбранному пользователю. |
| ➖ | **Забрать доступ** (`room:access:remove`) | Отзывает персональный доступ у выбранного пользователя. |
| 📝 | **Название** (`room:rename`) | Изменение названия голосового канала с защитой от rate limits. |
| 👑 | **Передать** (`room:owner`) | Передача прав владельца комнаты другому участнику. |
| 👢 | **Выгнать** (`room:kick`) | Принудительное отключение участника из комнаты. |
| 🔇 | **Мут** (`room:mute`) | Локальное отключение микрофона выбранному участнику. |
| 🔊 | **Вернуть звук** (`room:unmute`) | Снятие локального мута с участника. |

---

### 🎙️ In-Voice меню (`room:vc:manage`)

При включенном режиме голосового управления бот публикует выпадающий список в чат созданной комнаты:

- 📝 **Переименовать:** Быстрое изменение имени комнаты.
- 👥 **Изменить лимит:** Установка лимита мест.
- 🔒 **Закрыть / Открыть:** Быстрое переключение приватности.
- 📋 **Вайтлист:** Просмотр и управление списком допущенных пользователей.
- 👑 **Передать владельца:** Выбор нового владельца из меню участников.
- 👢 **Выгнать:** Быстрый кик нарушителя.
- 🔇 **Управление мутами:** Настройка звука для гостей комнаты.
- 🎵 **Soundpad:** Включение/выключение саундборда Discord (`UseSoundboard`).
- 🎮 **Активности:** Разрешение встроенных игр и YouTube Watch Together (`UseEmbeddedActivities`).

## 🚀 Быстрый старт

### Требования

- **Node.js** 22+ или **Bun** 1.3+
- **Docker** и **Docker Compose** — рекомендуется для продакшена
- Discord Bot Token с включенными интентами:
  - `Server Members Intent`
  - `Message Content Intent`

---

### Вариант 1: Запуск через Docker Compose

1. **Клонируйте репозиторий:**

   ```bash
   git clone https://github.com/shzanya/room-manager.git
   cd room-manager
   ```

2. **Создайте файл окружения:**

   ```bash
   cp .env.docker .env
   ```

   Заполните переменные:

   - `DISCORD_TOKEN` — токен бота из Discord Developer Portal
   - `DISCORD_CLIENT_ID` — ID приложения бота

3. **Запустите стек:**

   ```bash
   docker compose up -d --build
   ```

4. **Проверьте статус сервисов:**

   ```bash
   docker compose ps
   curl http://localhost:9090/health
   ```

---

### Вариант 2: Локальный запуск

1. **Установите зависимости:**

   ```bash
   bun install --frozen-lockfile
   bun add tsx
   ```

2. **Запустите вспомогательные сервисы:**

   ```bash
   docker compose -f docker-compose.infra.yml up -d
   ```

3. **Настройте `.env`:**

   ```bash
   cp .env.example .env
   ```

4. **Запустите бота:**

   ```bash
   # Стандартный режим (без шардинга)
   bun run start

   # Или через Node.js напрямую
   bun run --cwd apps/bot start
   ```

## ⚙️ Конфигурация

### Переменные окружения (`.env`)

| Переменная | По умолчанию | Описание |
| :--- | :---: | :--- |
| `NODE_ENV` | `development` | Режим работы (`development` / `production`). |
| `DISCORD_TOKEN` | **обязательно** | Токен Discord-бота. |
| `DISCORD_CLIENT_ID` | **обязательно** | Application ID бота. |
| `DATABASE_URL` | `postgresql://...` | Строка подключения к PostgreSQL. |
| `REDIS_URL` | `redis://localhost:6379` | Подключение к Redis для очередей и кэша. |
| `DATABASE_SSL` | `false` | Использовать ли SSL для подключения к БД. |
| `LOG_LEVEL` | `info` | Уровень логирования (`debug`, `info`, `warn`, `error`). |
| `METRICS_PORT` | `9090` | Порт сервера метрик Prometheus и health check `/health`. |
| `ENABLE_SHARDING` | `false` | **Выключено по умолчанию.** |
| `TOTAL_SHARDS` | `3` | Количество шардов при включенном шардинге. |

> [!NOTE]
> **Шардинг отключен по умолчанию.** Для большинства серверов однопоточный режим обеспечивает быструю реакцию, экономию оперативной памяти и полноценную работу встроенного сервера метрик на порту `9090`.
>
> Если вашему боту требуется шардинг для крупных установок, установите `ENABLE_SHARDING=true` или запустите `npm run start:shard`.

## 🛠️ Команды бота

Все команды доступны администраторам с правом `ManageGuild`:

### `/setup basic`

Автоматический мастер первоначальной настройки.

**Опции:**

- `category` — категория, в которой будут создаваться приватные комнаты.
- `hub` — голосовой канал-создатель (`➕ Создать комнату`).
- `panel` — текстовый канал для кнопочной панели управления.

Если параметры не указаны, бот **автоматически создаст все нужные каналы и категорию с настроенными правами**.

### `/setup settings`

Интерактивный центр управления ботом прямо в Discord:

- 🎨 **Дизайн:** Выбор скина (**Niako** / **Aruku**), загрузка собственного баннера или URL, кастомный текст.
- 🎛️ **Управление:** Режим поверхностей (`chat`, `voice`, `both`), мгновенное удаление, статус приватности по умолчанию.
- 🎭 **Иконки:** Выбор пака иконок, настройка палитры перекраски — Neon, Dark, Pastel, Rainbow.
- 🛡️ **Роли:** Настройка запрещающих и разрешающих ролей для создания комнат.
- 🌐 **Язык:** Переключение между русским и английским языком.

### `/stats`

Подробная статистика системы:

- Задержка WebSocket, аптайм, среднее время обработки команд.
- Потребление памяти и нагрузка CPU.
- Количество активных комнат, серверов и пользователей.
